# Native study files

These are actual browser downloads for the source record, with the recipe at
operation 6 and independent setback half-width 2 bu. The chosen divisor is the
retreat difference. `wrong-divisor.csv` uses the pole-gap divisor instead.

Decompress `haidao-reading.html.gz` with `gzip -dk haidao-reading.html.gz` and
open the resulting HTML. It contains all ten readings, five whole source
openings, fonts, exact record and full licenses; it needs no scripts or network.
`haidao-reading.pdf` is the actual tagged 28-page A4 print of that file. The CSV
and SVG preserve exact record data and an equal-scale survey.

These five files were downloaded again on 2026-11-25 from the current build, in
the same two states, after the author-name and license change. Besides the
credit, they now include the independent and shared error-pair comparison added
on 2026-11-03, so the print grew from 25 to 28 pages. The public site gave
byte-identical HTML, CSV and SVG files. `scripts/artifacts.py` passed on them:
ten readings and 120 language fields per HTML, five source JPEGs recovered
byte-identical from the PDF, 4,602 words within page bounds. States, hashes and
changes: [examples-2026-11-25.json](../docs/evidence/examples-2026-11-25.json).
The October browser receipts in `docs/evidence/` record the earlier files.
