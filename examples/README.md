# Native study files

These are actual browser downloads for the source record, with the recipe at
operation 6 and independent setback half-width 2 bu. The chosen divisor is the
retreat difference. `wrong-divisor.csv` uses the pole-gap divisor instead.

Decompress `haidao-reading.html.gz` with `gzip -dk haidao-reading.html.gz` and
open the resulting HTML. It contains all ten readings, five whole source
openings, fonts, exact record and full licenses; it needs no scripts or network.
`haidao-reading.pdf` is the actual tagged 25-page A4 print of that file. The CSV
and SVG preserve exact record data and an equal-scale survey.
