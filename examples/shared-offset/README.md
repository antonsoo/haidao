# Shared additive offset at the source exercise

These files are actual local production-browser exports from the 2026-11-03
review. Allowance is ±2 bu; both selected errors are +2 bu. The adjusted pair is
125,129 bu, with height 1255 and distance 31250 bu. The original applied record
is still 123,127 bu. Both complete error-model bounds travel in the reading and CSV.

The 27-page PDF was printed by Chromium from the downloaded script-free HTML.
The source images, fonts and full notices are retained. Physical printing and
PDF accessibility are not claimed.

```sh
gzip -dc examples/shared-offset/reading.html.gz > /tmp/haidao-shared-reading.html
```

Open the decompressed file directly; no server, scripts or connection is needed.
Its reopen link points to the canonical project URL. This review did not publish
the addition there, so that URL may still serve an earlier edition.
